Geographic truth

ABA can receive registration signals from across Africa. Current operating activity is centered in South Africa, so South African Act 36 detail is shown first while other country records stay flexible. Fictional placeholder data throughout.

1. Authorised submitter & approved person

Are you authorised to submit registration information for this company/product?

The registrar requires a nominated approved person resident in South Africa (or a company with an SA-registered office) who is accountable for the application. A third party acts only under a letter of authority. Spec §5 / G13–G14.

Not authorised stop state

If the submitter is not authorised, the intake remains stopped and asks them to forward the link.

If you are a technical contributor rather than an authorised company representative, use ABA's future expert or technical-context route. This prototype does not allow third-party product registration reporting.

3. Product, regime and legal pathway

Sector category maps to the registrar's own function axis (Insecticide / Fungicide / Herbicide / Other incl. PGR, adjuvant, rodenticide). Mapping shown for review; specialist confirmation pending. Spec §5.1 / G10.
A biostimulant splits by claim: a plant-growth-regulator claim routes to agricultural remedy; a soil / nutritional input routes to fertilizer. This is ABA's documentary reading, not a confirmed fact. Spec §5.2 / §8 Q2.
Act 36 legal pathway and data-path tag are hidden unless Agriculture / Act 36 is selected. The old "M / L / K classification code" picker has been removed — B/K/L/M are registrar-assigned registration-number prefixes, not an applicant choice (see step 6). Spec §5.4 / G9.

4. Service / application type

Backlog and wait-time differ by type, so the type sits at the registrar's clock-granularity — keyed to the Service Request Form 14ARx codes. The types the SRF bundles under one code (generic vs parallel/daughter) are kept separate here because their official clocks differ. Spec §2.1 / G1–G4.

—
An Act 36 registration is valid for three years and must be renewed before 31 May. Renewal is itself a tracked application type. Spec §2.2 note / G15.

Statuses use friendly labels but map 1:1 to the five official Act 36 stages (Verification → Scientific screening → Evaluation → Decision → Appeal) plus the cross-cutting "referred back" case. Spec §3 / G6.

6. Reference and readiness

Reference comes in two stages that must not be conflated: a pre-registration file/application reference, and a post-registration L-number that exists only once a record is registered. Spec §4 / G8, G9.

Not issued — no number exists before a record reaches "Approved / registered". This is a lifecycle attribute, never asked at intake. Spec §5.4.

Dossier readiness

The dossier (List I + List II + supporting studies) is captured as a single readiness flag — never field-by-field. Spec §6 / G12.

Proof of payment

Proof of payment is a distinct mandatory artifact checked at verification — separate from the dossier. Missing either can continue for review, but blocks registrar packet inclusion.
