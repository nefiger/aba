# Registration Tracker Regulator Source Documents

These files are the primary external reference documents used for the ABA registration-tracker modeling pass.

They are stored in the repo for traceability and workshop/reference use.

They are not ABA-authored requirements documents.

Current files:
- `Application form_16.08.2023_Final.docx`
- `Service Request Form for Agricultural Remedies (2).doc`
- `Guide-Reg-Process-Agric-Remedies-2015  (time frame).pdf`
- `Guidelines on Data Requirements for Agricultural Remedies 2015 AVCASA.pdf`

Use them to verify:
- which terms are clearly source-defined
- which stages and service/application categories come from the regulator corpus
- where the ABA tracker model is introducing its own normalization layer
